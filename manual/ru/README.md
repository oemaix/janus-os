# Janus OS

Janus OS — это маршрутизатор на базе NixOS. Образ собирается на одном
компьютере и записывается на небольшую плату. Плата не собирает программы
и не вычисляет Nix.

Проект публичный и распространяется по лицензии Apache 2.0.

## Что можно сделать сейчас

В репозитории есть руководство и документы с определением системы. Образ
маршрутизатора, команды `janus` и `janus-build` ещё не реализованы. Для
работы с исходным кодом есть оболочка разработки: в корне репозитория
выполните `nix develop`. В Cursor и VS Code терминал открывает эту
оболочку как zsh.

## Что задано для маршрутизатора

- Маршрутизация между WAN и LAN и межсетевой экран.
- Корневая файловая система только для чтения; изменяемые данные — на
  одном разделе состояния.
- Туннель для обхода блокировок; движок по умолчанию — sing-box.
- Управление по SSH. Повседневные изменения, которые разрешает
  спецификация, — это действия обслуживания и короткий список горячих
  переопределений. Структурные изменения — это новый образ со сборочной
  машины.
