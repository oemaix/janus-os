# Janus OS

Janus OS یک مسیریاب بر پایه NixOS است. تصویر سیستم روی یک رایانه ساخته
می‌شود و روی یک برد کوچک نوشته می‌شود. خود برد نرم‌افزار را نمی‌سازد و Nix
را ارزیابی نمی‌کند.

این پروژه عمومی است و تحت مجوز Apache 2.0 منتشر می‌شود.

## اکنون چه کاری ممکن است

راهنما و سند تعریف سیستم در همین مخزن هستند. تصویر مسیریاب و فرمان‌های
`janus` و `janus-build` هنوز پیاده‌سازی نشده‌اند. برای کار روی کد منبع یک
پوسته توسعه وجود دارد: در ریشه مخزن `nix develop` را اجرا کنید. در Cursor
و VS Code پایانه همین پوسته را با zsh باز می‌کند.

## آنچه برای مسیریاب مشخص شده است

- مسیریابی میان WAN و LAN، همراه با دیوار آتش.
- فایل‌سیستم ریشه فقط‌خواندنی، و داده‌های تغییرپذیر روی یک پارتیشن وضعیت.
- تونل عبور از سانسور، با sing-box به‌عنوان موتور پیش‌فرض.
- مدیریت از راه SSH. تغییرهای روزمره که مشخصات اجازه می‌دهد، کار نگهداری و
  فهرست کوتاهی از بازنویسی‌های فوری هستند. تغییر ساختاری یعنی یک تصویر تازه
  از ماشین ساخت.
